Vurix 개인정보 처리방침

최종 업데이트: 2025년 2월 12일

1. 수집하는 개인정보

Vurix 앱은 사용자의 서버 접속 정보를 저장하여 편리한 로그인을 지원합니다. 수집 및 저장되는 정보는 다음과 같습니다.

  • 사용자가 입력한 서버 접속 정보: IP 주소, 포트 번호, 사용자 ID, 비밀번호
  • 접속된 서버로부터 받은 데이터(예: CCTV 영상, 상태 정보 등)는 앱 내에서만 표시되며, 외부 서버로 전송되지 않습니다.

※ Vurix 앱은 서버로부터 사용자 개인정보(이름, 이메일 등)를 가져오지 않습니다.

2. 개인정보 이용 목적

수집된 정보는 다음과 같은 목적을 위해 사용됩니다:

  • 사용자의 편리한 로그인 지원 (서버 정보 자동 저장)
  • 사용자가 지정한 서버에 접속하여 영상 및 데이터 조회

3. 개인정보 보관 및 보호

  • 저장된 접속 정보(IP, Port, ID, Password)는 사용자의 기기 내에만 저장되며, 외부 서버로 전송되지 않습니다.
  • 비밀번호는 암호화된 형태로 저장됩니다.
  • 사용자는 앱 내 설정을 통해 저장된 정보를 언제든지 삭제할 수 있습니다.

4. 개인정보 제공 및 공유

Vurix 앱은 사용자의 개인정보를 제3자에게 제공하거나 공유하지 않습니다.

5. 사용자 권리 및 선택

사용자는 다음과 같은 권리를 가집니다:

  • 앱 내에서 저장된 접속 정보를 삭제할 수 있습니다.
  • Vurix 앱을 삭제하면 모든 저장된 접속 정보(IP, Port, ID, Password)가 기기에서 자동 삭제됩니다.

6. 보안 조치

  • 접속 정보 저장 시 암호화 적용
  • 서버와의 통신 과정에서 안전한 보안 프로토콜(예: SSL/TLS) 사용
  • 비밀번호는 앱 내 설정을 통해 변경 가능

7. 개인정보 처리방침 변경

개인정보 처리방침이 변경될 경우 앱 내 공지 및 업데이트를 통해 안내드립니다.
